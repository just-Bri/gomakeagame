# Combat + Progress

Last updated: 2026-09-20

Reusable Classic-flavored helpers extracted while building Forever Bound.

| Package | Role |
|---------|------|
| `combat` | Swing timer, tab-target cycle, melee reach test |
| `progress` | Slow XP tables + overflow leveling |
| `project` | Isometric soft-3D box projection (placeholder assets) |
| `move.Transform3` | XZ ground pose + yaw helpers |

Games own class kits, rage/mana, quest scripts, and AI. Engine keeps the
bits a second title (or TD with melee blockers) would otherwise copy.
